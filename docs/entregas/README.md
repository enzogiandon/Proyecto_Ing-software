## 📂 Organización Interna Estándar

Cada carpeta de entrega (`entrega-XX/`) respeta la misma convención:
- `README.md`: Resumen ejecutivo, pautas de evaluación y accesos externos (Forms, Taiga).
- `final/`: Documentos finales entregados a la cátedra según las plantillas oficiales.
- `borradores/`: Espacio de trabajo colaborativo para aportes individuales de los integrantes.
- `plantillas/`: Copia de respaldo de las plantillas provistas por los docentes.
